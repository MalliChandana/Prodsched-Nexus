IMPORTANT
- Your original project folder was not changed.
- This ZIP is a separate updated copy.
- The original data files and tests are included.
- The Python virtual environment and temporary cache folders are not included.
  This is normal; Python will use the requirements.txt file to install packages.

HOW TO OPEN IN VS CODE
1. Extract this ZIP to a folder, for example Desktop\ProdSched-Nexus-Updated.
2. Open VS Code.
3. Choose File > Open Folder and select the extracted ProdSched-Nexus folder.
4. Open Terminal > New Terminal.
5. Run these commands one by one:

   python -m venv .venv
   .venv\Scripts\activate
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   streamlit run app.py

6. The website should open at http://localhost:8501.
7. Keep the terminal open while using the website.

TO RUN TESTS
After installing the requirements, run:
   python -m pip install pytest
   python -m pytest -v

NOTE ABOUT TESTING
The code was checked for Python syntax. Automated tests could not be run in this working environment because OR-Tools is not installed here. Install requirements.txt in your own environment before running the tests.
